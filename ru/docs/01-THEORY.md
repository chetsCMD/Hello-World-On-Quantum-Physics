# 01 · Теория

## 1. Постановка задачи

Событие **E**: *без участия человека* в памяти компьютера возникает исполняемый образ
программы, которая выводит строку `Hello, World`, и процессор его исполняет.

Формализация. Образ программы — строка из N бит, `|H⟩ = |h₁h₂…h_N⟩`.
Состояние памяти — вектор в гильбертовом пространстве размерности 2^N:

```
|Ψ⟩ = Σ_x c_x |x⟩,   Σ |c_x|² = 1
```

Нужная нам вероятность — по правилу Борна:

```
P(E) = |⟨H|Ψ⟩|²
```

Если у нас нет информации о состоянии (максимально смешанное состояние, принцип безразличия),
то |c_x|² = 2^−N для любого x, и

```
P = 2^−N = 2^−8L
```

Это и есть «чистая» вероятность одной конфигурации.

## 2. Допущения модели

| № | Допущение | Значение по умолчанию |
|---|---|---|
| D1 | Образ программы — минимальный ELF x86-64, печатающий строку | L = 128 Б, N = 1024 бит |
| D2 | Область памяти фиксирована: ОС просто исполняет регион (число позиций K = 1) | K = 1 |
| D3 | Все 2^N конфигураций начальной области равновероятны | равномерное |
| D4 | Бит = двухъямная система; переход между ямами — туннелирование или тепловой/радиационный сбой | модели A–C |
| D5 | Вывод считается состоявшимся после декогеренции пиксельного состояния | класс `Observer` |

Если K > 1 (программа может появиться в любом из K мест), время уменьшается ровно в K раз,
т.е. поправка на log₁₀K ≈ 11 для 16 ГиБ. На фоне 10^250 это шум, но класс
`WaitingTimeEstimator` её учитывает.

## 3. Три модели времени ожидания

**Модель A — эргодический предел.** Система делает максимально возможное число различимых
квантовых переходов в секунду. Для энергии E это теорема Марголуса–Левитина:

```
Γ_max = 2E / (π ħ)
```

Для компьютера массой 1 кг (E = mc²): Γ_max ≈ 5,4·10^50 переходов/с (ультимативный лэптоп Ллойда).
Ожидаемое время: T_A = 2^N / Γ_max.

**Модель B — туннелирование.** Бит хранится зарядом за барьером. Вероятность туннелирования
по ВКБ: `T = exp(−2κd)`, `κ = √(2mV)/ħ`. Для совпадения нужно, чтобы n = N/2 неверных
бит перевернулись в одном временно́м окне Δt.

**Модель C — космические лучи.** То же, но частота переворота бита берётся из реальной
статистики мягких ошибок DRAM (~1000 FIT/Мбит ⇒ 10^−12 сбоев на бит в час),
окно — период регенерации DRAM (64 мс).

## 4. Наблюдатель и коллапс

До вывода пиксельное состояние — суперпозиция «пиксель горит / не горит» для каждой позиции
символа. Правило Борна задаёт вероятности исходов, оператор проекции
`P̂ = |Hello⟩⟨Hello|` описывает измерение «на экране написано Hello, World».
Декогеренция делает пиксельный базис *указательным*: экран быстро (~10^−20 с) «забывает»
суперпозиции. Честная оговорка про необходимость наблюдателя — в [FAQ](05-FAQ.md).

## 5. Что здесь не учтено

- Реальные биты коррелированы: не все 2^N конфигураций достижимы мягкими ошибками из заданного состояния.
- Не учитывается взаимодействие образа с загрузчиком (права, формат файла, MMU).
- Времена > 10^100 лет вне применимости космологии: протон, возможно, распадётся, звёзды
  погаснут задолго до этого. Формулы остаются корректными «в вакууме».
