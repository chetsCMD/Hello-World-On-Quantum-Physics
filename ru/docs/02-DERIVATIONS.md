# 02 · Выводы формул

Константы (CODATA 2018): ħ = 1,054571817·10⁻³⁴ Дж·с, c = 299 792 458 м/с,
mₑ = 9,1093837015·10⁻³¹ кг, 1 эВ = 1,602176634·10⁻¹⁹ Дж, 1 год = 3,15576·10⁷ с.

## 1. Чистая вероятность

`P = 2^−N`, значит `log₁₀ P = −N·log₁₀2 = −0,30103·N`.

| L (Б) | N (бит) | log₁₀ P |
|---|---|---|
| 22 | 176 | −52,98 |
| 128 | 1024 | −308,25 |
| 142 | 1136 | −341,97 |

## 2. Модель A: Марголус–Левитин

Скорость ортогонализации состояния со средней энергией E: ν ≤ 2E/(πħ).

```
E = m c² = 1 кг · (299792458)² ≈ 8,988·10¹⁶ Дж
Γ_max = 2E/(πħ) ≈ 5,43·10⁵⁰ с⁻¹      (log₁₀ = 50,734)
```

Ожидаемое время (малая p): `T_A = 1/(Γ_max · P)`, т.е.

```
log₁₀ T_A[с] = N·log₁₀2 − 50,734
```

Для L = 128: `308,25 − 50,73 = 257,52` ⇒ T_A ≈ 10^257,5 с ≈ 10^250,0 лет.

## 3. Модель B: туннелирование (ВКБ)

Барьер Si/SiO₂ для электрона: V = 3,1 эВ = 4,967·10⁻¹⁹ Дж, эффективная масса m* = 0,5 mₑ,
толщина d = 5 нм.

```
κ = √(2 m* V)/ħ = 6,378·10⁹ м⁻¹
T = exp(−2 κ d) = exp(−63,78) = 1,99·10⁻²⁸     (log₁₀ T = −27,70)
```

Частота попыток ν = V/h = 7,50·10¹⁴ Гц. Скорость туннелирования на бит:

```
r = ν · T ≈ 1,49·10⁻¹³ с⁻¹    (log₁₀ r = −12,83;  среднее время ≈ 10^5,3 лет)
```

В окне Δt = 1 нс каждый из n = N/2 «неверных» бит должен перевернуться независимо:

```
P_окно = (r Δt)ⁿ,    log₁₀ P_окно = n · log₁₀(r Δt) = 512 · (−21,83)
T_B = Δt / P_окно
```

Для L = 128: log₁₀ T_B[с] = 11165,8 ⇒ ≈ 10^11158 лет.

## 4. Модель C: мягкие ошибки

SER ≈ 10⁻¹² сбоев/бит/час ⇒ r_C = 2,78·10⁻¹⁶ с⁻¹ на бит (log₁₀ = −15,556).
Окно — период регенерации DRAM Δt = 64 мс.

```
T_C = Δt / (r_C Δt)ⁿ,    log₁₀ T_C[с] = −n·log₁₀(r_C Δt) + log₁₀Δt
```

Для L = 128: ≈ 10^8574,9 с ≈ 10^8567 лет.

## 5. Вероятность за время жизни Вселенной

Возраст Вселенной U = 4,35·10¹⁷ с (log₁₀ = 17,64). При T ≫ U:

```
P_U ≈ U / T      ⇒    log₁₀ P_U = 17,64 − log₁₀ T[с]
```

| L | A | B | C |
|---|---|---|---|
| 22 | ≈ 1 (180 с ≪ U) | 10^−1894 | 10^−1455 |
| 128 | 10^−239,9 | 10^−11148 | 10^−8557 |
| 142 | 10^−273,6 | 10^−12370 | 10^−9495 |

Число шагов 1-кг ультимативного компьютера за возраст Вселенной: `Γ_max · U ≈ 10^68,4`.
Нужно было 10^308,25. Не хватает ~239,9 порядков.

## 6. Декогеренция пикселя

```
τ_D = τ_R · (λ_th/Δx)²,   λ_th = ħ/√(2 m k_B T)
```

Электрон, T = 300 К: λ_th ≈ 1,2 нм. При Δx = 1 мкм и τ_R ~ 10⁻¹⁴ с:
`τ_D ≈ 10⁻¹⁴ · (1,2·10⁻³)² ≈ 1,5·10⁻²⁰ с`. Иллюстративная оценка порядка величины.
