# Руководство разработчика (язык `.Ψ`)

`.Ψ` — декларативный ООП-язык для описания физических систем. Файл = один класс.
Тела методов записываются формулами.

## Синтаксис

```
класс Имя [наследует Базовый] {
    константа  имя : тип = значение      // фундаментальные величины
    поле       имя : тип                 // состояние объекта
    метод      имя(аргументы) → тип := формула
}
```

- `⟨a|b⟩` — скалярное произведение, `|x⟩` — вектор состояния, `Ô` — оператор.
- `log₁₀`, `exp`, `√` — стандартные функции. `:=` — определение, `=` — равенство.

## Диаграмма классов

```
HelloWorldUniverse (точка входа)
 ├─ FundamentalConstants     ħ, c, mₑ, eV, k_B, год
 ├─ ProgramImage             L, N, |H⟩, P = 2^-N
 ├─ MemoryCell               ВКБ-туннелирование
 ├─ CosmicRaySource          SER, окно регенерации
 ├─ Hamiltonian              Γ_max (Марголус–Левитин)
 ├─ WaveFunction             |Ψ⟩, правило Борна
 ├─ Observer                 декогеренция τ_D
 ├─ CollapseOperator         P̂ = |Hello⟩⟨Hello|, коллапс при выводе
 ├─ WaitingTimeEstimator     модели A, B, C
 └─ UniverseTimeline         возраст Вселенной, P_U
```

## Принципы

1. Один файл — одна физическая ответственность.
2. Никаких магических чисел: константы только из `FundamentalConstants`.
3. Каждая формула либо выведена в [02-DERIVATIONS.md](02-DERIVATIONS.md), либо стандартна.
4. Результаты — логарифмы (log₁₀), потому что числа больше, чем double.
